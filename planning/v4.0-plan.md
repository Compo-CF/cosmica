# Cosmica 4.0 plan (branch `v4.0`, started 2026-11-10)

**Goal:** stop the game ending. Players hit the 1e300 ceiling in 2–6 days and run
out of things to do (Thenungod 5★ UK, Candeloro1 4★ US). 4.0 removes the ceiling,
adds a fourth prestige layer above the Multiverse, and brings the look and feel
up to the top idle games. Ships as a major update with its own In-App Event and
featuring nomination.

Decisions (Anthony, 2026-11-10): version **4.0** on its own branch (3.5.0 cross-promo
shelf ships separately from `main`); **new layer** as well as extending the
existing ladders; **visual overhaul** ("play with the big boys"); the rating-prompt
fix rides with 4.0.

## Phase 0 — Number type ✅ (this commit)
- `Cosmica/Shared/Big.swift`: mantissa × 10^exponent, reaches ~1e(9e15). NaN → 0,
  ±∞ → ±max, so a runaway formula can never freeze a save again.

  builds can still read 4.0 saves until a player passes 1e300), string past it.

## Phase 2 — Economy without a ceiling
**Finding (endgame_v2.py, 2026-11-10):** removing the cap with today's rules is a
runaway. Active player: 1e300 day 6.3, 1e1000 day 8.5, ~1e99,000 day 30,
~1e2.6 billion day 90 (2,000 cosmoi). Idle: 1e300 day 44.6, 1e1,401 day 60,
1e224,296 day 90. Each layer multiplies the one below, so the *exponent* grows
geometrically and numbers stop meaning anything.
**Damping test:** past 1.8e308, count every order of magnitude of the production
multiplier at d (a "dilation"). d=0.5: active walls at ~1e609, idle reaches 1e437
by day 90. d=0.3: walls ~1e395. So a dilation turns runaway into a soft wall, and
the Omniverse's job is to raise d step by step (Echoes buy dilation back), which
gives the new layer a clear purpose and keeps growth earned. Needs Anthony's OK.

- Port `planning/endgame_v1.py` to log10 space (`endgame_v2.py`) so it can run past
  1e308; find what the growth looks like with no cap for idle / active / 24/7 players.
- Targets: idle player reaches the new layer in ~3–4 weeks, active in ~1–2; nobody
  "finishes" in under 2 months; every layer still has a next goal on screen.
- Extend: Cosmos Goals past 1e300 (formula already 1e(36+4n)), achievement tiers
  (1e400, 1e1000, 1e10,000…), weekly-challenge targets, tier names past Vigintillion.
- Remove `GameEngine.ceiling` and every "capped 1e300" clamp.

## Phase 2/3 spec — DECIDED 2026-11-10: dilation + Echoes (Anthony)
Modeled in `planning/omniverse_v1.py` (log space, 180 days):
- **Dilation:** past 1.8e308, each ×10 of production counts at d. d0 = 0.5.
  d ≥ ~0.65 brings the runaway back, so it is capped below that.
- **Omniverse door:** first run past 1.8e308. **Collapse** pays
  Echoes = floor(10^((log10 bestRun − 308.25) / 100)); resets shards, fragments,
  sparks, Void Wonders and the Cosmos Goal ladder (goal counts cosmoi since the last
  collapse). Keeps Cosmic Wonders, lifetime cosmos count, achievements, purchases.
- **Echoes:** unspent ones multiply production ×(1 + E) *after* dilation; spend on
  "Thin the Veil" (+0.01 d per level, 12 levels → 0.62, cost 5·3^k), then automation
  (auto True Cosmos, auto Collapse), then later nodes / challenge runs.
- Result: active door day 6.4, an Omniverse every ~3 days, best run 1e224 (d30) →
  1e1,367 (d180), no runaway. Idle: door day 45, one every ~16–21 days (automation
  nodes will speed this; the model's idle player prestiges by hand every 8 h).
- Save fields: `echoes`, `lifetimeEchoes`, `omniverseCount`, `cosmosSinceOmniverse`
  (defaults to `cosmosCount` so current goals don't move), `omniverseNodeLevels`.

## Phase 3b — Rifts (challenge runs) — APPROVED 2026-11-10 (all 5); visual direction: layer palettes
Built as: goal for tier k = (0.6, 0.8, 1.0)·log10(best run ever) at entry (min 1e100),
so a Rift is a real challenge at any stage. Entering resets the run like a Big Bang
(no shards paid). Heavy Veil reward trimmed to +0.7%/tier (cap stays under 0.65).
Unlock after the first Omniverse collapse. Entering a Rift starts a fresh run (like a
Big Bang) under one rule; reaching the Rift's goal in that run pays a permanent
reward, once per tier (3 tiers per Rift, goals 1e100 / 1e200 / 1e300). Leaving a
Rift early costs nothing. Rewards stack with everything and are kept forever.
| Rift | Rule | Reward per tier |
|---|---|---|
| Dim Stars | Generators 9–16 produce nothing | Generators 1–8 ×10 |
| Silent Void | Void Sparks and Reality Fragments give no bonus | Fragment and spark yield ×1.5 |
| Heavy Veil | Dilation starts at 1e100, at 40% | +1% dilation, past the Veil's cap (max 0.64) |
| Lone Hand | No automation; taps ×100 | Taps ×5, and the tap floor becomes 1 s of production |
| Short Night | Offline earnings off; production ×3 | Offline cap +12 h |
Model check before building: each tier should take roughly one Omniverse cycle
(~3 days active) and lift the wall by about one Thin the Veil level.

## Phase 3 — Fourth layer (needs a design pass with Anthony)
Pattern the genre's best games use: each new layer **automates the one below**, so
the old loop becomes background and the new one is the game.
Proposal to react to:
- **Unlock:** first time a run passes **1.8e308** (Double's limit, "Breaking the
  Ceiling") — the moment old saves were stuck at becomes the door.
- **Reset:** collapses the Multiverse (sparks, Void Wonders) like the Multiverse
  collapses cosmoi.
- **Name: the Omniverse, currency Echoes** (Anthony, 2026-11-10).
- **Spend:** a permanent tree whose first nodes automate True Cosmos and Multiverse
  collapses (with thresholds, like auto-Big-Bang), then multipliers, then new
  Wonders; plus a few "challenge runs" (a run with a rule, e.g. no generators 5–8)
  that pay a permanent bonus — the depth Candeloro1 asked for.
- New generator tier(s) or a generator "ascension" so the Observatory screen
  itself changes, not just the numbers.

## Phase 4 — Visual overhaul ("play with the big boys")
Start with an **audit**: capture every screen (Mac simulator, iPhone 17 + SE + iPad),
list what reads as amateur next to the top idle games, then fix in this order:
1. **Design system:** one type scale, spacing grid, color tokens per layer (Big
   Bang / Cosmos / Multiverse / new layer each get a palette), one card + button
   component used everywhere (today each view styles its own).
2. **Hero scene:** the Observatory background reacts to progress (star density,
   nebula color, galaxies appearing per layer) — SpriteKit or Metal shader.
3. **Number feel:** rolling tickers, per-second gain floaters, milestone bursts,
   prestige transitions with weight (screen-filling, sound, haptics).
4. **Information design:** clear "next goal" strip on every layer, progress bars to
   each unlock, a stats page.
5. **Robustness:** Dynamic Type up to XXL without clipping, VoiceOver labels,
   Reduce Motion, iPad layout, SE-size layout, dark-only contrast check, 120 Hz
   without battery cost, no main-thread hitches on prestige.
6. New store screenshots + preview video built from the new look (PPO stopped
   11-10, page is free to change).
