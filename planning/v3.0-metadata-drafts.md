## 3. Reviewer Notes for v3.0 submission

```
Version 3.0.0 is a major feature release. Changes:

Automation feature set (gated behind the new Automation Core non-consumable IAP OR a 4-hour rewarded-ad trial):
- Auto-buy for individual generators, unlocked in stages via a new Autonomy branch on the Cosmic Shard skill tree
- Auto-prestige (Big Bang) at a player-set threshold

- "Reactor ready" when the player has accumulated meaningful shards

Home-screen widget:
- New WidgetKit extension with Small and Medium sizes showing stardust/sec + shard progress
- Reads game state from shared UserDefaults via an App Group entitlement

No new tracking. No new ATT prompt. No changes to Game Center or CloudKit sync.
All existing saves migrate cleanly (added fields use `decodeIfPresent` with sensible defaults).

Rewarded-ad flow (existing GoogleMobileAds SDK 12.x, already reviewed) now offers "Try Automation for 4 hours" as an additional reward type in the Shop.

Test account credentials: not required. The app has no login. Automation Core can be exercised via sandbox purchase or by watching a rewarded ad in the Shop.
```

## 10. Post-launch watch items (first 30 days)

- **Automation Core attach rate** — % of DAU that own or trial. Target: 8-12% attach in first 30 days is strong for this SKU
- **Trial-to-purchase conversion** — % of trial-users who buy within 7 days of trial. Target: 15-25% is genre-typical
- **D7 / D30 retention delta vs v2.1** — automation SHOULD improve retention; if it doesn't, something's wrong
- **Notification opt-in rate** — % of users who accept the notification permission. Target: 40-60% if the ask copy is honest
- **Widget install count** — hard to measure directly; use "App from widget" launches as a proxy
- **Crash rate** — WidgetKit + App Groups + UNUserNotificationCenter are all first-time; watch Organizer closely for the first 2 weeks
